# GGAX Consulting — Client Review Preview

Static preview build of the GGAX Consulting site, published for client review.

- **Live preview:** https://dizzafizza.github.io/ggax-site-preview/
- **Build mode:** static (`REACT_APP_STATIC_MODE=true`) — content is compiled from
  `static-content.json`. There is no backend attached, so the chatbot, contact-form
  submission, and the admin panel are intentionally disabled and not reachable.

This repository contains **compiled output only**. Application source, the Python
backend, and project history live in a separate private repository.
